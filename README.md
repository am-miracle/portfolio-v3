# Portfolio | Miracle Jude

Personal portfolio built with Astro, TypeScript and Tailwind CSS v4, with a WebGL 3D portrait on the home page.

## Stack

- Astro (static output, `ClientRouter` page transitions)
- Tailwind CSS v4
- GSAP and Lenis for motion and smooth scroll
- Three.js for the 3D portrait

## development

```sh
npm install
npm run dev  
npm run build
npm run preview
```

Blog posts come from Hygraph at build time. Set `HYGRAPH_ENDPOINT` (see `.env.example`); without it the blog still builds.
